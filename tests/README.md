# Tests

The Catch2 suite covers the B+ tree’s configuration validation, empty lookups,
row zero, duplicate keys, leaf splits and separator lookups, cascading internal
splits, root growth, and mappings after sequential and shuffled inserts.

Use the [build and CTest commands](../README.md#run-the-tests) from the
repository root. The first configure fetches Catch2 v3.5.4 from GitHub.
